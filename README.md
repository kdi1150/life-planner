# 인생 플래너

남은 인생을 동그라미 그리드로 보여 주고, 매일 루틴을 지킬 때마다 그 동그라미를 채워 가는 심플한 플래너 앱입니다.

- 앱 주소: https://kdi1150.github.io/life-planner/
- 폰에 설치: 아이폰은 사파리에서 공유 → "홈 화면에 추가", 안드로이드는 크롬에서 ⋮ → "앱 설치"
- 기록은 각 폰에만 저장됩니다(로그인·서버 없음).

## 파일
- `index.html` 앱 전체 (화면·계산·저장)
- `manifest.webmanifest` 앱 이름·아이콘 설정
- `sw.js` 오프라인 실행 (파일을 바꾸면 안의 VERSION 값을 올려 주세요)
- `icons/` 앱 아이콘
